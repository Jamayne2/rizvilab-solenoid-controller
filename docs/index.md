
# RIZVILAB Solenoid Controller

**BeagleBone Black | Python | PyQt4 | GPIO Control**

Welcome to the technical documentation for the RIZVILAB Solenoid Controller.

This project provides a touchscreen-based interface for operating three independently controlled solenoid valves on the RIZVILAB test stand.

## Important Safety Notice

This controller uses software-based GPIO commands and
timers. A software OFF command does not independently
verify physical valve closure.

Review the safety documentation and approved hardware
procedures before operating the equipment.
